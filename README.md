# FourZero Status

Uptime monitoring and public status page for [FourZero](https://fourzero.work), powered by [Upptime](https://upptime.js.org/).

## Monitored services

- FourZero Website
- FourZero Contact
- FourZero Services
- WordPress REST API

Checks run every 5 minutes through GitHub Actions.
